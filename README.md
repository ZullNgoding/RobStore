# 🛒 RobStore

**RobStore** is a simple **e-commerce web application** built as a learning project and portfolio showcase.  
The project demonstrates **Full-Stack Web Development skills** including frontend, backend, and database integration.

---

## ✨ Features
- 🔐 **User Authentication** (Register & Login)
- 📦 **Product Management** (CRUD operations)
- 🛍️ **Shopping Cart**
- 💳 **Basic Checkout & Order Flow**
- 📱 **Responsive Design** (Desktop & Mobile friendly)

---

## 🛠️ Tech Stack
**Frontend**
- React / Next.js
- TailwindCSS

**Backend**
- Node.js + Express
- REST API

**Database**
- PostgreSQL / MySQL (configurable)

**Others**
- Git & GitHub
- Vercel / Netlify (frontend deployment)
- Render / Railway (backend deployment)

---

## 🚀 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/ZullNgoding/RobStore.git
   cd RobStore
   
2. Install Dependency
   ```bash
   npm install
   
3. Create environment file
   ```bash
   Create a .env file in the project root and add your configuration:
   DATABASE_URL=your_database_url
   JWT_SECRET=your_secret_key

4. Run the development server
   ```bash
   npm run dev
